CentOS Linux Server Commands

Check Operating System:
cat /etc/os-release

Check IP address:
ip addr

Test Internet:
ping -c 4 google.com 

Test network connection:
ping -c 4 [Unbuntu IP]

Test SSH service:
sudo systemctl enable --now sshd
sudo systemctl status sshd

Install SCP/SSH tools:
sudo dnf install openssh-server openssh-clients -y 

Create test file:
echo "Hello from CentOS" > test.txt

Test file:
cat test.txt
